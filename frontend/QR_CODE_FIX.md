# QR Code Fix for We-Roster Mobile

## Issue
The QR code generated by `npm start` was showing "No available data found" when scanned, preventing connection to the development server.

## Root Cause
The issue was caused by:
1. Outdated Expo dependencies causing compatibility issues
2. Missing development client configuration
3. Incomplete deep linking setup for QR code URLs
4. Tunnel URLs not being properly handled by the app

## Solution
Updated the Expo development server configuration with proper development client setup and enhanced deep linking support.

## Changes Made

### 1. Updated Dependencies
- Fixed outdated Expo packages using `npx expo install --fix`
- Updated to compatible versions of expo, expo-dev-client, and jest-expo

### 2. Enhanced package.json scripts
- `npm start` - Uses tunnel mode with development client (recommended)
- `npm run start:go` - Uses tunnel mode with Expo Go
- `npm run start:lan` - Uses local network with development client
- `npm run start:localhost` - Uses localhost with development client
- `npm run start:clear` - Clears cache and starts with tunnel + dev client

### 3. Enhanced app.json configuration
- Added development client configuration with silent launch
- Added proper URL schemes for iOS and Android
- Enhanced intent filters to handle tunnel URLs (*.exp.direct, *.exp.host)
- Added support for both custom scheme and exp:// URLs

### 4. Created expo.json
- Separate configuration file for better development setup
- Ensures proper development client handling

## Usage

### For Development Build (Recommended)
```bash
npm start
```
This starts the development server with tunnel mode and development client, generating a QR code that works with your custom development build.

### For Expo Go
```bash
npm run start:go
```
This starts with tunnel mode for use with the Expo Go app.

### Alternative Options
```bash
# Use local network (if on same WiFi)
npm run start:lan

# Use localhost only (for local testing)
npm run start:localhost

# Clear cache and start fresh
npm run start:clear
```

## Prerequisites
1. **Development Build**: You need a development build of the app installed on your device
2. **Internet Connection**: Required for tunnel mode
3. **Updated Dependencies**: All Expo packages should be up to date

## How It Works
- **Development Client**: Custom app build that can load development bundles
- **Tunnel Mode**: Uses ngrok to create a public URL that tunnels to your local server
- **Enhanced Deep Linking**: Proper URL scheme handling for both tunnel and custom URLs
- **Silent Launch**: Development client launches without showing splash screen

## Troubleshooting
If QR code still shows "No available data found":
1. **Install Development Build**: Make sure you have a development build installed, not Expo Go
2. **Try Expo Go**: Use `npm run start:go` if you're using Expo Go instead of development build
3. **Clear Cache**: Run `npm run start:clear` to clear Metro cache
4. **Check Network**: Ensure stable internet connection for tunnel mode
5. **Update Dependencies**: Run `npx expo install --fix` to ensure all packages are compatible
6. **Rebuild App**: You may need to rebuild your development build after configuration changes
