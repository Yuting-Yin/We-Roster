## Java Coding Standard for WeRoster (version1)

## 1.Formatting and Style
- max line length **120**, 2 space indents

## 2.Naming and Structure
- Classes: PascelCase, variable names camelCase, constants should be in all Uppercase

## 3.Exceptions and Errors
- Wrapexceptionswithcontextandrethrowinsteadofswallowingexceptions

## 4.Logging
- UseSLF4J insteadof`System.out`

## 5.Testing
- UseJunit

## 6.Security
- 403 vs 401 policy enforced centrally
