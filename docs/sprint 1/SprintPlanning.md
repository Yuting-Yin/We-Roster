## Sprint Goal

The goal of Sprint 1 is to establish a clear understanding of client requirements, deliver foundational project documentation, and set up a self-managed and self-organized team structure. Specifically, this includes:

- Clarifying client needs and writing the **Requirement Elicitation document**.
- Producing additional supporting materials (e.g., UML diagrams, User Stories) where relevant.
- Establishing clear team roles and responsibilities.
- Delivering a **high-fidelity prototype in Figma**.
- (Optional) Delivering a working **full-stack demo**.

---

## Definition of Done (DoD)

- Requirement Elicitation document completed.
- Supporting design artifacts (UML diagrams, User Stories， etc.) created as needed.
- HiFi prototype completed in Figma.
- Demo prepared (if feasible).
